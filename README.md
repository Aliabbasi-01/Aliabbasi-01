I'm **Muhammad Ali**, a Software Engineer from Pakistan who enjoys turning ideas into practical, scalable software.

- 🚀 Software Engineer & Application Developer
- 📱 Android development with Kotlin and Java
- 🦋 Cross-platform application development with Flutter

- 🏗️ Interested in clean architecture, maintainability and performance
- 🌱 Continuously learning and exploring new technologies
- ☕ Fueled by curiosity, coffee and the occasional debugging adventure
